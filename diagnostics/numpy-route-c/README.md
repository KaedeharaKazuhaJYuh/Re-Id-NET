# 路线 C：身份约束下的分支去冗余 · 最小复现实验

本地可运行的合成特征原型，源于《总结与思路.pdf》第 7 页路线 C。
研究问题：排序更不相似时，两分支是否真的更互补，还是只是更常反向排序？

## 运行

Python 3.10+，仅需 NumPy。无需新 GitHub 仓库、GPU、图片或真实身份数据。
如已有 NumPy，可跳过第一行。

```text
python -m pip install -r requirements.txt
python -m unittest -v
python probe.py --seeds 7 13 21 --steps 180 --out results.json
```

结果 JSON 包含逐种子验证集／测试集、汇总均值与样本标准差。
三个集合按合成身份分离。每个身份有两种合成相机条件，测试固定相机 0
为 query、相机 1 为 gallery。同一种子下四组共享数据、初始化、每步
P=6、K=4 取样和训练预算。两条固定的特征生成路径共享部分信息，
再各学一个线性投影和身份分类头；并非图像骨干。

| 模式 | 相同的身份交叉熵 + batch-hard triplet 之外的变量 |
| --- | --- |
| none | 无 |
| ratr_proxy | 比较同一查询下正样本相似度的排序，以及负类质心相似度的排序；对两组分别用 tanh 平滑，再最小化平均一致性。温度 0.15，是代理，不是原论文复现。 |
| cov | 两分支单位嵌入的批内交叉协方差平方均值 |
| cov_id | 同一协方差项，再加两个身份分类头的中心化 logits 均方差 |

独立报告两个分支与分数平均融合的 mAP、Rank-1，另报融合 mAP 减去
最佳单分支 mAP。辅助诊断包括 gallery 内正样本／负质心 Kendall tau-a、
反序比例和交叉协方差。gallery 内排名诊断与跨相机检索是两种不同的量。
不要把 tau 下降、协方差下降或合成 mAP 波动当成真实任务改进。

## 如何升级为正式实验

1. 确认原论文与其许可代码，核对 RATR 的温度、归一化、权重及原实现；
   本包不含原论文训练代码，也不下载数据。
2. 在同一个 PyTorch MambaVision + HCEN 工程中接入这四组，固定骨干、
   输入、监督和每身份采样；检查梯度与首个 epoch 的耗时和显存。
3. 仅用从训练身份切出的验证集选权重；固定预算后在获准数据上运行
   三种子官方评估，报告每个分支与融合的 mAP / Rank-1 和波动。
4. 若融合没有稳定收益，或单分支判别下降，不继续堆叠损失。当前
   NumPy 原型及自定义匹配协议不能作为论文指标或部署依据。
